# Internationalization (Phase 2 scaffold)

- Library: `i18next` + `react-i18next`.
- Locale files: `frontend/src/i18n/locales/{en,es}.json`.
- User preference: `localStorage` key `landgrant.locale`; shell language toggle in `AppLayout`.

## Adding strings

1. Add keys under `translation` JSON (mirror structure in `en` and `es`).
2. Use `const { t } = useTranslation();` and `t('nav.workbench')` in components.

## Extraction (future)

When copy grows, adopt a message extraction tool (e.g. `i18next-parser`) in CI and fail on missing keys for `en`.
